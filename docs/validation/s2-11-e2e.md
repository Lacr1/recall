# S2-11: end-to-end tests and accessibility checks

> Date: 2026-10-09 · Machine: Windows 10 Pro 19045 · Electron 44.7.0 · Playwright 1.64.0 · axe-core 4.14.0

## How it runs

`npm run test:e2e` builds the app, then Playwright launches the built app (`out/`) through Electron. Each spec file gets:

- a **fresh data folder** and its own Electron profile under `tests/.tmp/e2e/`. Runs work while a normal Recall window is open (`RECALL_E2E=1`).
- a **copy of the fixture corpus**, so tests never touch `tests/fixtures`.
- a **fake Ollama** on a random loopback port (`tests/support/fake-ollama.ts`). It answers version, tags, embed (deterministic hashed vectors), pull (streamed progress) and chat (streamed). It can stop and restart on the same port. The engine reaches it through `RECALL_OLLAMA_URL`, and the loopback-only check still applies.
- **replacements in the main process** for the folder picker and for opening or revealing a file, installed from the test through Playwright. Nothing in the shipped code is test-only apart from the two environment variables above.

**Accessibility:** axe-core scans 15 screen states, including every dialog. Serious or critical findings fail the test; lower ones are recorded as annotations. Final result: **0 findings at any severity**.

**Results:** 11 / 11 passed in about 29 s; `--repeat-each 3` gave 33 / 33 with no flaky tests.

## Bugs the tests found (fixed)

| Bug | Effect for users | Fix |
|---|---|---|
| "Delete all data" left the window on Settings | Data was wiped, but the app did not return to setup until restarted. The renderer's `location.reload()` was cancelled by the app's own navigation block. | Main clears stored settings and reloads the window itself |
| "Inferred:" sentences inside a paragraph were not marked | A model's guess looked like a cited fact unless it started a new paragraph | Each sentence starting with "Inferred:" is marked, wherever it starts in a paragraph |
| Onboarding step dots had a label screen readers may not read (serious) | Screen readers skipped "Step 1 of 3" | Given an image role |
| No main landmark on onboarding; no top-level heading on Search; Ask skipped a heading level (moderate) | Harder screen-reader navigation | Added the landmark, a hidden heading and corrected the heading level |

## Not covered

- **The native folder picker dialog** and **"Start Ollama"** (launches the real Ollama app). Check both by hand.
- **Real models:** E2E uses fake vectors and canned answers. Ranking quality is covered by `npm run test:live`, not here.
- **Flow 4, "data size decreases":** not asserted. SQLite keeps freed pages, so the file does not shrink after a folder is removed (no `VACUUM` yet).
- **Screen readers, 200% scaling, high contrast:** these are manual checks (S3-09). axe catches markup problems only.
- **Packaged build:** E2E runs against `out/` with the development Electron binary, not the installer. The packaged app is covered by the smoke test only.
